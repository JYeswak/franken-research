## Method

For each ledger row I asked: **can the companion be completed as a planning
artifact without answering this?**

- **RESOLVED-with-resolution** — the answer already exists in the evidence
  pack, the companion's own text, or the playbook's normative sections; the
  unknown is stale or a scoping/convention decision with a playbook-prescribed
  answer. The resolution text is written here for the integrator to apply.
- **TARGETED-with-predicate+owner+S3-step** — the unknown is answerable during
  a future pickup's execution (bench build / truth-pack assembly / gate
  wiring), not a defect in the plan itself. Each row names the concrete
  resolution predicate, the owner role (from the playbook's role set), the S3
  step that answers it, and the TARGETED reclassification text.
- **STAYS-BLOCKS_PLAN** — the pack does not answer it and no honest S3 step
  can; the plan genuinely cannot proceed without it.

Per the lane rules, no row was cleared by relabeling alone.
