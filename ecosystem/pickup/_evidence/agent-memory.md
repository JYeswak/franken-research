# Agent memory systems - evidence

Research-only evidence pack for the FrankenSuite project-pickup playbook (agent memory / long-term memory for agents: Mem0/Letta-class). Every repo below verified via `api.github.com` on 2026-09-23. File-level pointers verified via the GitHub contents API unless marked [README] (claim from the repo's own README text).

## Trend (owner/repo | stars | last push | why it evidences the trend)

- mem0ai/mem0 | 65,890 | 2026-09-23 | Largest memory-layer repo; README (April 2026) publishes its own LoCoMo 92.5 / LongMemEval 94.4 / BEAM scores after an algorithm rewrite, and open-sources its eval framework (`mem0ai/memory-benchmarks`, vendored as the `evaluation/` git submodule in the main repo, verified via `.gitmodules`). Ships Python + TS SDKs, per-agent-plugin SDKs (Strands, OpenClaw, n8n, Zapier...), and a server.
- SuperMemoryAI/supermemory | 30,841 | 2026-09-23 | Second-largest dedicated memory repo; monorepo (turbo.json, bun) with `packages/memory-graph`, per-SDK Python packages (openai-sdk, pipecat, cartesia...), MCP app, web + docs apps; per-SDK publish CI (`publish-*.yml`). README self-reports LongMemEval 85.86% single-pass (discloses their ~99% headline is an 8-variant ensemble).
- letta-ai/letta | 24,858 | 2026-09-10 | MemGPT successor ("stateful agents: AI with advanced memory"). **Caveat:** since restructuring, `letta-ai/letta` `main` is a landing page + `archive` branch; active code moved to `letta-ai/letta-code` (verified from `letta-ai/letta` README, raw.githubusercontent). Cite the pair, not the star count alone.
- letta-ai/letta-code | 3,412 | 2026-09-23 | Where Letta is actually developed: agent harness, terminal UI, App Server, channels; `python/letta_code` + TS `src/`. CI includes `nightly-update-smoke.yml`, `telegram-live-smoke.yml`, per-agent-watcher workflows.
- getzep/graphiti | 31,102 | 2026-09-23 | Temporal knowledge-graph library for agent memory (Zep's core); very active. Separate `server/`, `mcp_server/`, `spec/`, `signatures/` dirs; strict CI (lint, typecheck, codeql, Socket firewall, pinned action SHAs).
- getzep/zep | 4,929 | 2026-09-18 | Zep's production memory product repo; contains `benchmarks/locomo/` and `benchmarks/longmemeval/` harnesses plus a `zep-eval-harness/` (checkpointed, retried eval runs).
- snap-research/locomo | 1,185 | 2024-08-13 | **The benchmark repo itself.** "Evaluating Very Long-Term Conversational Memory of LLM Agents" (ACL 2024). Ships `data/locomo10.json`, `task_eval/` (evaluate_qa.py, evaluation_stats.py, per-provider LLM utils: gpt/claude/gemini/hf), `scripts/`, `generative_agents/`. Static since 2024 but still the cross-vendor lingua franca: Mem0, Zep, Graphiti, Hologres Open Memory, total-agent-memory and others publish LoCoMo numbers.
- xiaowu0162/LongMemEval | 1,104 | 2026-05-11 | **The benchmark repo itself** (ICLR 2025). Clean pipeline separation: `src/{generation,retrieval,index_expansion,evaluation,utils}` with `evaluate_qa.py`, `print_qa_metrics.py`, `print_retrieval_metrics.py`. Mem0, Supermemory, Mastra, Emergence, Chronos (PwC) all report LongMemEval(-S) numbers; community HF mirror `xiaowu0162/longmemeval-cleaned` widely used by third-party harnesses.
- mem0ai/memory-benchmarks | 113 | 2026-08-06 | **The benchmark harness repo itself** (Mem0's open-sourced eval framework, vendored as submodule into mem0). Layout: `benchmarks/{locomo,longmemeval,beam,common}/`, `configs/{azure-openai,ollama,openai}.yaml`, `results/`, `docker-compose.yml`. Shows how a vendor productizes memory eval: benchmark plugins + provider configs + checked-in results.

## Notes / caveats

- **Adopter claims are thin in this pack.** "Notable adopters" for these libraries mostly live in README logos and integration lists I did not individually verify from primary sources; I deliberately did not cite any. The trend evidence above rests on stars, push activity, and benchmark-publishing behavior (which is itself a form of adoption: Mem0, Zep/Graphiti, Supermemory, Mastra, Emergence, Chronos/PwC, Hologres all publish LoCoMo/LongMemEval numbers against the same two public benchmarks).
- **Supermemory's README is self-promotional.** Its ~99% headline is disclosed in the same README as an 8-variant ensemble; the single-pass 85.86% is the comparable number. Third-party `total-agent-memory` variants also self-report 95-96% with thinly-vetted methodology — treat indie benchmark claims as directional, not ground truth.
- **Mem0's README is honest about the platform gap:** the April 2026 numbers "reflect Mem0's managed platform, which includes proprietary optimizations not available in the open-source SDK." Copy the disclosure practice, not just the scores.
- **LoCoMo repo is static (last push 2024-08-13)** but remains the canonical dataset file (`data/locomo10.json`) everyone downloads; activity now happens in downstream harnesses.
- **Adjacent, not included in the table:** `LangChain-AI/langchain` (146,931 stars, pushed 2026-09-23) and `microsoft/autogen` (61,123, pushed 2026-04-15) are the agentic frameworks that *consume* memory layers, but they are not memory systems per se. AutoGen's push is 5 months old — check its current status separately before citing it as "active".
- **Star-count trap on Letta:** 24.8k stars belong to the now-landing-page repo; active development is `letta-ai/letta-code` (3.4k stars, daily pushes). Always cite the pair.
