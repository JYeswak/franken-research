# Multi-agent protocols - evidence

All repos verified 2026-09-23 via `api.github.com/repos/<owner>/<repo>` unless noted.
Category: A2A/ACP-class protocols — standardized discovery, messaging, and task delegation between agents.

## Process practices worth copying (practice | repos exhibiting it | file pointers)

1. **Dedicated, versioned Technology Compatibility Kit separate from any SDK** | a2a-go | `a2aproject/a2a-go:e2e/tck/run_tck.sh`, `e2e/tck/orchestrate_tck.py` (clones `a2aproject/a2a-tck` and runs it against a local System Under Test), `e2e/tck/sut.go`, `e2e/tck/sut_test.go`, `e2e/tck/sut_agent_executor.go`. Copy: keep the conformance suite in its own repo so every implementation (and a clean-room rewrite) tests against the same bar.
2. **Wire-format conformance corpus shared across SDK repos, generated by diffing two implementations** | a2a-js, a2a-python | `a2aproject/a2a-js:test/proto_json_conformance.spec.ts` — header states cases were "found by round-tripping a shared corpus through this SDK and a2a-python and diffing the output"; known-broken cases use `it.fails` so the marker starts failing when fixed (fix can't land without flipping it). Copy: build a shared message corpus and run it through every implementation; track known failures as tests that must flip, not as skipped TODOs.
3. **Backward-compat suites pinned to older spec versions** | a2a-python, a2a-go | `a2aproject/a2a-python:tests/compat/v0_3/` (15 files), `a2aproject/a2a-go:e2e/compat/`, plus `a2a-go:a2acrypto/sign_test.go` (signature/canonicalization of Agent Cards). Copy: keep per-spec-version compat test dirs so vN servers keep working with vN-1 clients.
4. **Multi-transport parity testing (A2A mandates JSON-RPC, gRPC, REST expose the same operations)** | a2a-go, a2a-python | `a2aproject/a2a-go:a2asrv/jsonrpc_test.go`, `a2asrv/rest_test.go`, `a2asrv/sse_test.go`, `a2agrpc/v0/`, `a2agrpc/v1/`, `e2e/jsonrpc_test.go`, `e2e/push_configs_test.go`; `a2aproject/a2a-python:tests/integration/` (25 files), `scripts/docker-compose.test.yml`. Copy: if the protocol has multiple bindings, test the same behaviors on every binding, not just one.
5. **Spec-repo CI as a lint gate (proto + docs + spelling)** | a2aproject/A2A | `a2aproject/A2A:specification/a2a.proto` + `specification/buf.yaml`, `specification/buf.lock`, `specification/.api-linter.yaml` (protobuf lint via buf); `.github/workflows/` (11: `linter.yaml`, `spelling.yaml`, `release-please.yml`, `conventional-commits.yml`, `docs.yml`). Copy: spec changes go through machine-checked lint before human review.
6. **Cross-language interop CI as a named workflow** | agent-network-protocol/anp | `agent-network-protocol/anp:.github/workflows/rust-python-interop.yml`, `tests/rust_interop_config.json`, `tests/e2e/`, `tests/system/`, `scripts/run_all_tests.py`, `testdata/` fixtures (`did_transition/`, `direct_e2ee/`, `group_e2ee/`). Copy: name the interop matrix explicitly in CI (language-pair workflows), check in wire fixtures under `testdata/`, one script to run everything.
7. **Protocol-machinery unit tests at the message layer (verify, sign, register)** | fetchai/uAgents, ANP | `fetchai/uAgents:python/tests/test_protocol.py`, `test_protocol_spec.py`, `test_msg_verify.py`, `test_agent_registration.py`; `agent-network-protocol/anp:anp/unittest/` (74 files), `anp/direct_e2ee/`, `anp/e2e_encryption_hpke/`. Copy: unit-test the handshake/crypto/discovery primitives independently of any LLM.
8. **Auth/signature conformance as first-class tests** | a2a-js, a2a-python | `a2aproject/a2a-js:test/signature.spec.ts`, `test/auth*` in a2a-python `tests/auth/`, `tests/server/` (39 files). A2A v1.0 added JWS-signed Agent Cards — the SDKs test the signing path directly. Copy: security features (signing, auth schemes) get their own spec files, not incidental coverage.

## Notes / caveats

- **Thin category, honest assessment.** Interop work is concentrated inside one project's SDK matrix (A2A's four official SDKs + its TCK). ANP (1,435 spec stars, 351 impl stars) is the only other spec with a community; its impl repo's `unittest/` count (74 files) is strong but the cross-language interop workflow covers only rust-python, not the full five-language matrix. There is no second fully independent A2A implementation outside the a2aproject org found in this sweep — the "interop" tested is mostly self-interop.
- **Consolidation is the trend.** IBM's ACP (1,016 stars) was archived Aug 2025 and merged into A2A (corroborated by two independent third-party research docs found via web search: github.com/pete-builds/writ-protocol `docs/research/02-prior-art.md` and github.com/brunocapelao/miniautogen `docs/agent-frameworks-research-2026.md`). Cisco's `agntcy/acp-sdk` is also archived (verified: pushed 2025-06-16, archived). A new clean-room project should treat A2A v1.x as the target and ACP as historical.
- **TCK is young.** `a2aproject/a2a-tck` (51 stars, pushed 2026-09-01) exists and a2a-go wires it into e2e, but it's the least-maintained piece of the A2A testing story — no evidence yet that all four SDKs run it in CI.
- **Coral Protocol excluded.** Search surfaced Coral-Protocol org activity but a crypto-token tracker page (holder.io) flagged the org as abandoned with ~0 recent commits and its example repos show ~600-day staleness in search results; not verified via API and not cited per the no-memory rule — treated as negative evidence for category breadth.
- **MCP deliberately excluded.** Model Context Protocol is agent-to-tool, not agent-to-agent; ANP's own docs (`agent-network-protocol/agentnetworkprotocol` blogs) make this distinction explicit.
