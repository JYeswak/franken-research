What they publicly do

Lists Higher Order Company on his GitHub profile and describes himself as author of Kind and HVM [Verified: GitHub profile]. Top committer (870 commits) on Bend 2, a language where a human states intents as laws (LAWS.bend) and the AI must supply a proof (PROOF.bend) that the checker accepts [Verified: bendlang/bend README and contributors API]. Relevance to our work

5 of 5 lenses: verification, agents, memory, research-method

Bend 2 (Apache-2.0) is an adoptable 'laws plus machine-checked proof' gate for AI-written code, and two franken-research cohort packets assess Bend-based repositories. OptMem is a compact memory design to compare with ee/cass, though it has no license.

What we would study next

  1. OptMem's design: append-only fixed-width log, rebuildable summary tree, merges surfaced inline by 'note', one wake budget knob (github.com/VictorTaelin/OptMem). A minimal memory contract to benchmark ee/cass against (wake cost, recall fidelity, no background jobs). No license, so study the design only. Effort: small.
  2. Re-try the beads_bend packet's kill test on Bend v2.0.27 (github.com/bendlang/bend/releases/tag/v2.0.27). Taelin ships near-daily releases, so the beads_bend packet's kill test (a quantified codec round-trip law) should be re-tried on the current checker. Effort: medium.
  3. AI-scripts 'board' and 'long' tools (github.com/VictorTaelin/AI-scripts). A small multi-advisor review panel and a goal/work/review loop; comparable to multi-model review and agent-loop patterns. Effort: small.

Before reusing anything: Bend 2 is Apache-2.0 (OSI) [Verified: GitHub license API, 2026-09-25, evidence/licenses.jsonl]; install is curl | sh from bend-lang.com. OptMem, AI-scripts, Interaction-Calculus and HVM4 have no LICENSE file (all rights reserved by default): study only, do not copy code or the prompt text. Bend performance and checker-speed claims ('checks in under a second') are maintainer claims; our own beads_bend packet records 316-529 s and 11-12.8 GB proof checks at real-tool scale.
