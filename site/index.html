Data note: window.FRANKEN_DATA and its field schema

This page and the map above both read from one global, window.FRANKEN_DATA (loaded from assets/data.js). Aggregate counts on the map and table are computed from these records at render time.

FRANKEN_DATA.repos is an array of 44 records, one per repo:

name
Repo name. Full brief at briefs/<name>.html.
trl
TRL as a display string ("4–5"); support assets read "N/A".
trlLow / trlHigh
Numeric TRL bounds. Ranges are plotted and sorted as spans, never midpoints.
techNA
true when TRL is N/A as technology (a support asset, not a technology).
nodus
NODUS ring: Invest, Pilot, Explore, or Monitor.
license
License verdict in plain words.
licenseKey
rider (MIT + AI-lab rider), mit (plain MIT), none (no license file).
ci
CI (continuous integration) state at the assessed commit, in plain words.
ciKey
C1: CI green at the pin. C2: CI red at the pin. C3: CI exists, no pin verdict. C4: no test CI (deploy-only at most). C5: CI disabled or deleted. C6: tests only on maintainer-private machines.
release
Release-artifact status at the pin.
blurb
The one-paragraph verdict.

FRANKEN_DATA.licenseClasses labels and explains the three license states. FRANKEN_DATA.ringDefinitions glosses the four rings. FRANKEN_DATA.visualEncoding pins rendering parameters such as the rider-dome radius.
